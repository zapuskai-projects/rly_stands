# Автоматический отчёт проверки задания

При каждой проверке задания платформа формирует отчёт по полученным фактам. Студенту не нужно собирать его вручную или пересылать скриншоты.

Отчёт содержит время, идентификатор попытки и её метку. Для каждой проверки сохраняются проверяемый объект, наличие объекта, доступные факты и конкретная причина ошибки. Неполученные факты означают «проверка не состоялась», а не отсутствие результата работы.

Для SQL-файла новый пульт сообщает рабочую папку, имя, версию набора, наличие обычного файла, размер, дату изменения и SHA-256 прочитанных байтов. Отдельно различаются отсутствующий файл, пустой файл, папка вместо файла, формат RTF, ошибка запроса и недоступный ClickHouse. Проверка не определяет, есть ли несохранённый текст в редакторе: она фиксирует состояние на диске.

Для таблицы ClickHouse сохраняются проверяемая база и имя, наличие таблицы, движок, колонки и число строк. Для SQL-запроса — число строк результата, колонки и ошибка ClickHouse. Другие проверки сохраняют компактные сведения, которые уже предоставляет исполнитель; содержимое файлов и полные ответы сервисов в сводку не включаются.

Студент видит конкретную причину под непройденным пунктом последней проверки; пульт печатает её рядом с подсказкой. Администратор открывает профиль сотрудника → «Обучение» → «Попытки» → нужное задание → «Ответ»: там доступны читаемый отчёт и существующая кнопка копирования. Структурированный отчёт сохраняется в `result.diagnostics`; текст — в `submission.preview`. Права доступа остаются правами существующей попытки.

Отчёт сохраняется отдельно от обрезаемых больших `observations`, поэтому многочисленные операции банка не вытесняют ошибку SQL. Старый пульт совместим: сведения, которых он не прислал, отмечаются неизвестными. После обновления пульта новая проверка дополнит отчёт метаданными файлов. Потерянные подробности старых проверок восстановить по обрезанному ответу нельзя.

В попытке хранится отчёт её последней проверки с временем сбора фактов.

Состояние выполнения условий и начисление зачёта не меняются. Неизвестное наличие файла не подменяется выводом «студент не сохранил файл».
