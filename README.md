# Набор стендов «Запускай» на вашем компьютере

Здесь живут стенды, которые не помещаются на общий сервер: RabbitMQ, Kafka, Camunda, Elasticsearch, PostgreSQL, ClickHouse, Prometheus и Grafana, контракты и диаграммы, Linux-сервер. Они работают у вас в Docker и запускаются одной командой. Какие из них вам доступны, решает платформа.

## Что нужно

- Docker Desktop (Windows, macOS) или Docker Engine с плагином compose (Linux).
- Память для Docker: 8 ГБ, лучше 16.
- 12 ГБ свободного места на диске и интернет для первой загрузки образов.

## Установка

1. Установите Docker Desktop с [docker.com](https://www.docker.com/products/docker-desktop/). На Mac с чипом M1–M4 выбирайте «Apple Silicon», на Mac с Intel — «Intel chip». Проверка:

   ```
   docker --version
   ```

2. Отдайте Docker память. macOS и Windows с Docker Desktop: Settings → Resources → Memory, 8 ГБ или больше, затем Apply & restart. На Windows с WSL 2 память задаётся в файле `%UserProfile%\.wslconfig`, раздел «Если не хватает памяти» ниже.

3. Скачайте набор:

   ```
   git clone https://github.com/zapuskai-projects/rly_stands.git
   cd rly_stands
   ```

   Нет git — скачайте [архив](https://github.com/zapuskai-projects/rly_stands/archive/refs/heads/main.zip) и распакуйте в любую папку.

4. Получите токен на платформе: «Стенды» → «Как установить» → «Получить токен». Токен показывается один раз.

5. Запустите пульт и вставьте токен (ввод скрытый):

   ```
   ./stand
   ```

   На Windows запускайте `stand.cmd`. Пульт поздоровается по имени и покажет ваши стенды.

6. Проверьте, что всё готово:

   ```
   ./stand doctor
   ```

Первый запуск стенда качает образы, это несколько гигабайт. Повторные запуски быстрые.

## Работа с пультом

`./stand` без аргументов открывает меню: стрелки выбирают стенд, Enter запускает или останавливает, `З` открывает задачи, `П` проверяет текущую задачу, `В` (или `q`) выходит. Пульт запускает только те стенды, которые вам назначены, и отказывает, если не хватает памяти, называя, что остановить.

| Команда | Что делает |
|---|---|
| `./stand login` | ввести токен |
| `./stand logout` | забыть токен на этом компьютере |
| `./stand status` | показать состояние стендов |
| `./stand up kit-rabbitmq kit-kafka` | запустить стенды (можно `rabbitmq`) |
| `./stand down [стенд…]` | остановить стенды, без имён — все |
| `./stand reset <стенд>` | удалить контейнеры и данные стенда |
| `./stand doctor` | проверить Docker, память, сеть, платформу, токен и список проверок пульта |
| `./stand tasks` | список ваших задач на компьютере со статусом |
| `./stand task start <номер>` | начать задачу: запустить нужные стенды, подготовить их, показать условие и вашу метку |
| `./stand task` | показать условие текущей задачи ещё раз |
| `./stand check` | проверить текущую задачу: пульт соберёт факты на вашем компьютере, платформа решит, зачтено ли |
| `./stand verify <задача>` | проверить задачу эталоном (только администратор, `--yes` без вопросов, `--no-reset` без стирания данных) |

Токен действует ограниченное время (по умолчанию 14 дней), потом нужен новый. Если токен отозван, пульт сам остановит стенды в течение 10 минут и покажет причину при следующем запуске. Если связи с платформой нет больше суток, стенды тоже останавливаются.

## Адреса и учётки

Все порты открыты только на вашем компьютере (`127.0.0.1`).

| Стенд | Адреса | Вход |
|---|---|---|
| RabbitMQ | панель http://localhost:15672, AMQP `localhost:5672` | `guest` / `guest` |
| Kafka | брокер `localhost:19092`, AKHQ http://localhost:18080 | без входа |
| Camunda (Operaton) | http://localhost:18090 | `demo` / `demo` |
| Elasticsearch | http://localhost:9200, Kibana http://localhost:5601 | без входа |
| PostgreSQL | `localhost:15432`, база `student`; база банка — `bank` | `student` / `student` |
| Контракты и диаграммы | PlantUML http://localhost:18100, Prism http://localhost:18110 | без входа |
| ClickHouse | http://localhost:18123 (`/play`), native `localhost:19000`, база `student` | `student` / `student` |
| Prometheus и Grafana | Prometheus http://localhost:19090, Grafana http://localhost:13000, учебное приложение http://localhost:18200 | Grafana: `admin` / `admin` |
| Linux-сервер | SSH `ssh student@127.0.0.1 -p 12222`, приложение http://localhost:18300 | `student` / `student` |
| ЗапускБанк (учебный) | интернет-банк http://localhost:18400, операционный офис http://localhost:18400/office, документы проекта http://localhost:18400/docs, API http://localhost:18400/api/docs | вход по телефону клиента и коду из журнала СМС |

ЗапускБанку нужны PostgreSQL, Kafka и RabbitMQ: пульт сам запускает их перед банком, но они должны быть вам назначены. Данные банка лежат в базе `bank` в PostgreSQL; `./stand reset kit-bank` стирает эту базу.

Prism отдаёт заглушку по файлу `work/openapi.yaml`; изменили файл — остановите «Контракты и диаграммы» и запустите снова.

## Задачи

Каждая задача набора выдаёт вам метку из шести символов, например `k7f3qa`. Все имена, которые вы создаёте по условию, начинаются с неё: так проверка отличает вашу работу от чужой. Пульт собирает факты со стендов на вашем компьютере и отправляет их на платформу; сами стенды платформе не видны.

Если проверка пишет «проверка не состоялась», стенд не ответил: убедитесь, что он запущен (`./stand status`), и запустите проверку снова. Это не ваша ошибка. Если в списке задач написано «обновите набор», пульт не знает проверок этой задачи: выполните `git pull` и запустите `./stand` снова.

## Папка work

Ваши схемы, диаграммы, схемы данных и ответы кладите в папку `work/`. Пульт читает её, когда проверяет задачу, и никуда не отправляет.

## Обновление

В папке набора:

```
git pull
```

Пульт напомнит об обновлении, а если ваша версия ниже минимальной, откажется запускать стенды, пока вы не обновитесь.

## Если не хватает памяти

- Остановите лишние стенды: `./stand down kit-kafka`.
- Docker Desktop на macOS и Windows: Settings → Resources → Memory, поставьте 8 ГБ или больше и нажмите Apply & restart.
- Windows с WSL 2: создайте файл `%UserProfile%\.wslconfig` с содержимым

  ```
  [wsl2]
  memory=8GB
  ```

  затем в PowerShell выполните `wsl --shutdown` и снова откройте Docker Desktop.
- Elasticsearch с Kibana занимают больше всего памяти; запускайте их, когда остальное остановлено.

## Если не получается

- **Docker не запущен.** Откройте Docker Desktop и дождитесь статуса Running.
- **Порт занят.** Пульт назовёт порт. Остановите программу или контейнер, который его занимает, и запустите стенд снова.
- **Долго качается.** Первая загрузка — несколько гигабайт. Если `./stand doctor` пишет, что реестр не отвечает, проверьте сеть и повторите позже.
- **Windows, ошибка WSL.** PowerShell от администратора: `wsl --install`, затем перезагрузка.
- **Пульт просит обновиться.** `git pull` в папке набора.
- **Токен отозван или истёк.** Получите новый на платформе и выполните `./stand login`.
